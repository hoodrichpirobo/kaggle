## Topics Covered

- Basic Python syntax, variables, expressions, and operators
- Functions, arguments, defaults, and built-in help utilities
- Booleans, branching, and simple game logic
- Lists, slicing, mutation, and nested indexing
- Loops, comprehensions, and aggregate calculations
- Strings, tokenization, and dictionary-based lookups
- Imports, plotting helpers, and working with external libraries

## Notes

- These files are exported Kaggle notebook solutions and are not all runnable as standalone scripts.
- Several exercises depend on notebook-scoped helpers such as `q1`, `play_slot_machine`, `jimmy_slots`, and `full_dataset`.
- The external libraries exercise is best read alongside the Kaggle notebook because part of its setup is provided by the course runtime.
