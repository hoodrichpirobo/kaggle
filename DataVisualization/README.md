- Introduction to data visualization with Seaborn

- Bar charts and heatmaps for categorical data
- Scatter plots to explore relationships between variables
- Visualizing distributions with histograms and density plots
- Choosing the right plot type and applying custom styles
- Building an end-to-end visualization from a real-world dataset
